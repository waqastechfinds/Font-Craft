# Font-Craft

**Font-Craft** is a browser-based collection of font and text tools for creating stylish Unicode text that you can copy and use in social profiles, messages, and other supported platforms.

**Live website:** https://fontcraft.me/

## Features

- Generate fancy and aesthetic Unicode text styles.
- Copy generated text for use in supported apps and websites.
- Create text for social bios and messages.
- Use dedicated tools for different platforms and text needs.
- Access the tools directly in your browser without installing an app.

## How to Use

1. Open the [Font-Craft website](https://fontcraft.me/).
2. Enter or paste your text into a tool.
3. Choose a style or formatting option.
4. Copy the result and paste it into the app or website where you want to use it.

Availability and appearance can vary by platform because these styles use Unicode characters and the destination platform's font support.
